# BJM 通用迁移包 v1.4.1

在 v1.4 上只改了说明文字。协议的规则、脚本、图执行器和附带的 Agent Skills 0.6.16 都没有变，v1.4 的数据和检查点照旧能用。

## 下载哪一个

- **`bjm-portable-v1.4.1.zip`**：整个包，解压出来是 `bjm-portable/` 目录，和仓库里这一版的文件相同（`.github/`、`docs/releases/` 这类仓库用的文件不进包）。由发布工作流从这一版的提交用 `git archive` 生成。
- `LICENSE`、`THIRD-PARTY-NOTICES.md`：许可全文和第三方组件说明，包里也有同样的两份。

## 这一版改了什么

- **和小说写作工坊分开**：`SKILL.md` 的 description 加了一句“中文小说的写作、续写、改稿和审稿用小说写作工坊（novel-workshop），不用本技能”。两个技能装在同一个宿主里时，免得抢同一个请求。
- **改编依据写准确**：`references/bjm-v3.2.md`“改编依据”一节写明，当时依据的是 0.6.15 前后的 main 分支快照；表里列的上游路径在本包所带的 0.6.16 里都还在，其中 6 个改过，协议正文没有据此改写，也没有逐条重新对照。
- **版本记录**：`CHANGELOG.md` 改成按版本分节，写明日期按台北时间（UTC+8）记。
- `README.md` 标题改成 v1.4.1。

## 验证到哪一步

- 包里自带的测试：BJM 36 项、图执行器 6 项，在 Linux、Python 3.13 上全部通过。
- 泄露检查：没有作者的小说、原话和私人路径。
- 测试和检查都是同一个模型（Claude）的新实例做的，不是独立评审。

## 没有验证的

- 加的那句 description 在宿主里会不会真的让两个技能分开触发，没有实测。
- Windows、macOS。
